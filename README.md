# Dotfiles

Personal shell, prompt, Herdr, and Yazi configuration. Git configuration is intentionally not included; it will be handled separately. Omarchy/Hyprland and Neovim configurations live in their own repositories.

## Layout

- `.bashrc` → `~/.bashrc`
- `config/starship.toml` → `${XDG_CONFIG_HOME:-$HOME/.config}/starship.toml`
- `config/herdr/` → `${XDG_CONFIG_HOME:-$HOME/.config}/herdr/`
- `config/yazi/` → `${XDG_CONFIG_HOME:-$HOME/.config}/yazi/`

## Setup

Run `./setup.sh` as your regular user. It links the Herdr and Yazi directories, plus `.bashrc` and `starship.toml` (which are standalone files). Existing targets are moved to timestamped `.backup.*` siblings before linking. Running it again leaves correct links untouched.

Setup also installs missing Herdr plugins automatically. `config/herdr-plugins` lists plugin IDs and GitHub repositories; setup checks installed IDs and uses `herdr plugin install <owner>/<repo> --yes` for missing entries. Herdr and `jq` must be available; this step may download plugins.

**Herdr caveat:** linking the whole directory replaces access to the current installed plugin code and generated state; those remain safe in the backed-up directory but are not automatically migrated. Setup reinstalls missing Herdr plugins after linking. `config/herdr/plugins/config/` is tracked, while installed plugin code and common runtime files are ignored. The `herdr-splits.conf` file is regenerated by the Neovim plugin's `setup()`; change its options in `nvim-dotfiles` rather than editing the generated file directly. Inspect the backup before removing it.

The Bash configuration sources Omarchy's Bash defaults and expects Omarchy to be installed. Starship, Herdr, and Yazi must also be installed separately. `omarchy-bootstrap` already includes Yazi in its package installation list.
